Custom EVision vehicle-hire pricing, insurance and date-based fleet availability.

== Description ==
Initial staging test release. Classic WooCommerce product form, basket and checkout required.
Six per-vehicle rates, working-day notice, midday same-day cut-off, out-of-hours requests,
first-month/full payment options, insurance extras, eligibility notices and offline reservations.
See the included INSTALLATION.md and the repository README for setup and limitations.
